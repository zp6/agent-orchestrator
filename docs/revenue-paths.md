#### Deployment — operator-action TODO (Day 3, blocker)

**Why zero-touch wasn't viable:** The PR Review API uses `better-sqlite3` (native Node.js module),
which rules out Cloudflare Workers (V8 isolate, no native modules). All other platforms
(Vercel, Fly.io, Railway) require CLI auth tokens that do not exist in the fleet env.
This is a one-time operator setup, not a recurring dependency.

**Fastest path (Fly.io — ~5 minutes):**
```bash
# Operator runs once:
flyctl auth login
cd /path/to/agent-orchestrator
flyctl launch --name fleet-review-api --dockerfile Dockerfile.review-api --region sjc
flyctl secrets set STATE_DB_PATH=/data/state.db
# Deployment URL: https://fleet-review-api.fly.dev
```

**Alternative (Railway — ~3 minutes):**
- Connect GitHub repo at https://railway.app → New Project → Deploy from Repo
- Set `DOCKERFILE_PATH=Dockerfile.review-api` and `PORT=3100`
- Deployment URL will be auto-assigned (e.g. `https://fleet-review-api.up.railway.app`)

Once deployed, update this file's `deployment URL` field and `docs/treasury.md`.
