# Fleet PR Review API — Public Service

> **Revenue path #5** (ref: `docs/revenue-paths.md`, issue #1302)

The fleet exposes its existing PR review capability as a paid external service.
Anyone can submit a GitHub PR for review and receive a structured
`approve` / `request_changes` / `escalate` decision with detailed feedback.

---

## Pricing

| Tier | Price | What you get |
|------|-------|-------------|
| **Basic** | $0.10 / PR | Diff summary + approve/request-changes decision |
| **Deep** | $0.50 / PR | Full LLM review + security scan + multi-provider consensus (Claude + Deepseek R1) |

## Endpoints

### `GET /api/pr-review/info`

Returns pricing, wallet address, and capability metadata.

**Response:**
```json
{
  "name": "Fleet PR Review API",
  "pricing": {
    "basic": { "price_usd": 0.10, "description": "..." },
    "deep":  { "price_usd": 0.50, "description": "..." }
  },
  "payment": {
    "wallet_address": "0x468EC325f3797F5968dEcC757FA0B960Bd0f78Ef",
    "network": "Base (EVM, Chain ID 8453)",
    "supported_tokens": ["USDC", "DAI", "ETH"]
  },
  "disclosure": "..."
}
```

### `POST /api/pr-review/submit`

Submit a PR for external review.

**Request body:**
```json
{
  "repo":        "owner/repo",
  "pr_number":   42,
  "tier":        "deep",
  "payment_ref": "0xabc...123",
  "callback_url": "https://yourapp.example/webhook"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `repo` | string | ✅ | GitHub repo slug: `"owner/repo"` |
| `pr_number` | number | ✅ | PR number to review |
| `tier` | `"basic"` \| `"deep"` | ✅ | Review tier |
| `payment_ref` | string | ✅ | On-chain tx hash or Polar order ID |
| `callback_url` | string | optional | `https://` webhook URL for async result delivery |

**Response:**
```json
{
  "request_id":   "01ABCD...",
  "repo":         "owner/repo",
  "pr_number":    42,
  "tier":         "deep",
  "status":       "queued",
  "accepted_at":  "2026-04-29T20:00:00Z"
}
```

Once processing completes:
```json
{
  "request_id":    "01ABCD...",
  "status":        "complete",
  "decision":      "approve",
  "summary":       "No blocking issues found. Minor: ...",
  "completed_at":  "2026-04-29T20:01:30Z"
}
```

## AI disclosure

All reviews are generated by LLM models (Anthropic Claude, Deepseek R1) without
human review unless the `escalate` decision is triggered.

By submitting a PR you acknowledge AI authorship of the review output.
